# Three recorded cases

These are real saved AI outputs for fictional Canopia guests, recorded on 6 October 2026. They are supplied to make the research experiment reproducible without a fresh conversation or paid call.

| Case | Useful focus | Main caution |
|---|---|---|
| [Family holiday and anniversary](family-anniversary/README.md) | Different family interests, severe shellfish allergy, comfort, personal touches and optional experiences | Long conversation; selected brief underuses some everyday preferences |
| [Quiet anniversary in Prague](prague-anniversary/README.md) | Slow independent exploration, cafés, bookshops, dinner and sensory preferences | Reception is the handoff despite a wrong Concierge heading in the recorded draft |
| [Work trip and running](work-and-running/README.md) | Time pressure, an early run and distinct before/after breakfast preferences | Fictional identity; no real public running history can be inferred |

Each `case.json` includes the frozen hotel snapshot, original conversation, retained facts, selected brief and source provenance. The readable files reproduce that evidence, except for one explicitly labelled French-to-English card-message translation in the family case. The loader creates fresh database IDs and remaps message references; it does not transfer invitations or the original test account.

The active conversation prompt is v5.1, while these complete recorded conversations used v5. The saved baseline briefs use v4.2. This distinction is deliberate: later targeted prompt checks are not new full conversations. Existing outputs remain fallible examples, not expected answers to reproduce.
